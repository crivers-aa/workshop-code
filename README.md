# Workshop Code

A collection of React component pattern examples.

**Live demo:** [crivers-aa.github.io/workshop-code](https://crivers-aa.github.io/workshop-code/) 

## Quick start

```bash
yarn install
yarn dev
```

## Deploy to GitHub Pages

1. Push to GitHub and go to **Settings → Pages → Source → GitHub Actions**.
2. Every push to `main` deploys automatically via [the workflow](.github/workflows/deploy-pages.yml).
